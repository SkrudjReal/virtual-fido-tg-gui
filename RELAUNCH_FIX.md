# Повторный запуск GUI — 07.11.2026

Первый процесс Virtual FIDO остаётся работать после закрытия окна Edge. На Windows был подтверждён живой экземпляр на `127.0.0.1:8080`. Старая сборка при повторном запуске получала ошибку занятого порта и завершалась до отложенного открытия окна. В режиме без консоли ошибка не была видна.

Исправлено:

- Launcher резервирует порт до чтения vault и запуска фоновых задач.
- Если на этом порту отвечает существующий Virtual FIDO, повторный запуск сразу открывает его окно и завершает только новый launcher.
- Edge запускается с `--new-window`, без задержки, которая раньше не успевала сработать.
- Ошибки запуска, включая порт, занятый другим приложением, показываются в окне Windows. При `--no-browser` они выводятся в stderr.
- Манифест готового PE проверен: `requestedExecutionLevel="requireAdministrator"`. Он требует административные права; дополнительный UAC-запрос не нужен, когда запуск уже выполняется из повышенного процесса.

Проверено нативно на Windows:

- Старая сборка на занятом порту вернула код 1, исправленная — код 0.
- Новый сервер запускается; второй и третий запуск используют его, не завершая сервер.
- Второй запуск с намеренно некорректным тестовым vault не читает и не изменяет этот файл.
- Тестовое окно реально открылось, было закрыто и снова открылось повторным запуском. После закрытия сервер продолжал отвечать.
- Исходный пользовательский экземпляр не останавливался. Драйверы и существующий vault не изменялись.

Также выполнены полный Linux-набор с `CGO_ENABLED=0`, `go vet`, focused race checks и тесты распознавания существующего приложения. Проверка ресурсов выполнялась на готовом `.exe`, а не только на XML-исходнике манифеста.

Новая сборка: `release/relaunch-20261107/virtual-fido-gui.exe`. При запуске рядом с уже работающей версией она открывает её интерфейс. Чтобы полностью перейти на новый сервер, нужно сначала завершить прежний экземпляр; для устранения проблемы повторного открытия это не требуется.

Установка USB/IP-драйвера и реальные passkey-входы этим исправлением не проверялись.
